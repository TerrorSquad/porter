```
dist/

## 🔨 Building

# Distribution Notes

Distribution assets are under `nodejs/dist/`.

## Build

```bash
cd nodejs
npm run build
```

## Dist contents

Current outputs include:

- `nodejs/dist/porter.mjs`
- platform binaries (if generated by your build flow):
  - `nodejs/dist/porter-linux-x64`
  - `nodejs/dist/porter-macos-x64`
  - `nodejs/dist/porter-macos-arm64`
  - `nodejs/dist/porter-win-x64.exe`

## Verification

```bash
cd nodejs
node dist/porter.mjs --help
```
